# 🚀 AI-WEB-CALLING-AGENT

An automated Real Estate Lead system using Voice AI.

### 🛠️ Tech Stack:
* **Frontend:** Tally Forms
* **Automation:** n8n (Webhooks)
* **Voice AI:** Vapi.ai (Gemini 2.0 Flash)

### ⚡ How it works:
1. Lead enters data in Tally.
2. n8n processes the data into a dashboard.
3. User is redirected to a live Vapi AI Agent (Sarah) for consultation.
